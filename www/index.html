Разделы config.yaml
    config.yaml
    Путь для конфига:

    —

    Скомпилированный набор правил mihomo (.mrs): двоичный файл, в редакторе его не показать. Доступны скачивание, замена файлом с диска и удаление.

    Путь для конфига показан над этой панелью, его же кладите в path: у rule-providers.

    Хеш пароля панели

    Введите пароль — получите md5-хеш $1$… для переменной окружения WEB_PASSWORD_HASH контейнера.

    Логин задаётся в WEB_USER (по умолчанию admin). Старые имена BASIC_AUTH_USER и BASIC_AUTH_HASH тоже работают.

    AWG / WireGuard .conf → YAML

    Вставьте содержимое .conf (AmneziaWG или обычный WireGuard) — получите блок прокси type: wireguard для секции proxies.

    TrustTunnel .toml → YAML

    Вставьте TrustTunnel-конфиг .toml — получите блок прокси type: trusttunnel для секции proxies.

    OpenVPN .ovpn → YAML

    Вставьте OpenVPN-конфиг (со встроенными блоками <ca>/<cert>/<key> или auth-user-pass) — получите блок прокси type: openvpn.

    Бэкап и восстановление

    Выгружает и загружает всё сразу: config.yaml, pre/post-скрипты, proxy-providers/, provider-rules/.

    Бэкап содержит секреты открытым текстом: secret ядра, пароли и ключи прокси. Храните его так же аккуратно, как сам конфиг.

    Двоичные .mrs тоже входят — они лежат в бандле в base64.
